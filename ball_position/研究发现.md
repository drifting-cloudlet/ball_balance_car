### 2026-07-31 - 用户提供五点实际距离误差
- **关联轮次**：Round 10 / Scout
- **实测数据**：实际 `-10/-5/0/+5/+10 cm` 时，当前显示分别为 `-9.36/-4.65/0/+4.17/+8.25 cm`。
- **校正方向**：代码标定表采用“当前显示值 → 实际值”，即 `(-9.36,-10)`、`(-4.65,-5)`、`(0,0)`、`(4.17,5)`、`(8.25,10)`。
- **处理结论**：复用 CV 工程的分段线性插值函数；负侧和正侧分别校正，以补偿两侧不同的比例误差。
- **边界说明**：`[-10,+10] cm` 实测区间内插值；区间外按最外侧两点线性外推，需补充 `±12.5 cm` 实测点才能校准全量程边缘。
- **不变项**：零点位置、YOLO 检测、滤波、模型、UART 帧格式和丢球规则均不变。
- **来源**：用户 2026-07-31 实机测量数据与本地 CV 工程标定实现
- **状态**：已采纳；五点映射与 UART 主机回归通过，待板端复测

### 2026-07-31 - 尺面红色零点不在标定轴几何中点
- **关联轮次**：Round 9 / Scout
- **查询范围**：用户板端截图、`main.py` 标定轴动态尺寸和零线计算
- **关键发现**：MaixCAM2 的标定轴从输入坐标 `x=5` 到 `x=635`，旧零点固定取 50%，即 `x=320`；截图中尺面红色 `0` 的中心约为显示坐标 `x=743.5`，按 2.5 倍显示比例还原为输入坐标 `x=297.4`，对应轴比例约 `0.4641`。
- **处理结论**：采用 `AXIS_ZERO_RATIO=0.464` 的三点分段标定，使左端、红色零点、右端分别对应 `-12.5 cm`、`0 cm`、`+12.5 cm`。
- **不变项**：YOLO 检测、滤波、模型、阈值、UART 帧格式及丢球帧规则均不变。
- **来源**：用户 2026-07-31 板端截图和本地源码
- **状态**：已采纳；三点映射和 UART 主机回归通过，待板端画面对齐确认

### 2026-07-31 - 用户确认横轴坐标方向需反转

- **不变项**：YOLO 检测、滤波、模型、阈值、UART 帧格式及丢球帧规则均不变。

## API 用法记录

### MaixPy UART0
- **构造调用**：`uart.UART('/dev/ttyS0', 115200)`
- **写入调用**：`serial_device.write(payload)`
- **关闭调用**：`serial_device.close()`
- **来源**：本地 `CV_steer/maixcam2_steel_ball_uart/main.py` 及其回归测试
- **注意事项**：不配置 pinmux；逐帧发送路径不打印；短写视为失败。
