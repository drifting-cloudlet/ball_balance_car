 # ball_balance_car

  2026 年电赛 H 题车载平衡滚珠系统电控工程。

  本项目基于 **STM32F407** 与 **MaixCAM2**，结合红外循迹、视觉定位、串级 PID 和 ZDT 闭环步进控制，实现小车运动过程中钢球
  在指定位置的稳定控制。

  ## 功能特性

  - STM32F407 主控
  - 红外传感器循迹
  - MaixCAM2 钢球视觉检测与位置解算
  - 串级 PID 平衡控制
  - ZDT 闭环步进电机控制
  - 视觉数据串口传输
  - 钢球目标位置控制
  - 模块化外设驱动与应用代码

  ## 控制流程

  1. MaixCAM2 采集平衡区域图像。
  2. 视觉程序识别钢球并计算其位置坐标。
  3. 坐标数据通过串口发送至 STM32F407。
  4. STM32 根据目标位置与实际位置计算偏差。
  5. 串级 PID 输出电机控制量。
  6. ZDT 闭环驱动器控制步进电机调整平台姿态。
  7. 红外传感器提供车辆循迹信息。
  8. 系统持续闭环调节，使钢球稳定在指定位置。

  ## 编译与烧录

  ### STM32 程序

  1. 使用 STM32CubeMX 打开 Template.ioc。
  2. 检查时钟、GPIO、定时器和串口配置。
  3. 生成或更新 Keil 工程代码。
  4. 使用 Keil MDK 打开 MDK-ARM 目录中的工程文件。
  5. 编译工程并通过调试器烧录到 STM32F407。

  > 重新生成 CubeMX 代码前，请确认用户代码位于 USER CODE BEGIN 和
  > USER CODE END 区域内，防止自定义代码被覆盖。

  ### MaixCAM2 程序

  视觉部分包含两个主要模块：

  - ball_position：完成钢球检测和坐标计算。
  - ap_trans：完成图像或坐标数据传输。

  将对应程序部署到 MaixCAM2 后，根据实际串口配置连接 STM32。

  ## 使用步骤

  1. 检查电源、电机驱动器和传感器接线。
  2. 完成摄像头安装和视觉区域标定。
  3. 设置钢球的目标位置。
  4. 确认 MaixCAM2 能够稳定输出钢球坐标。
  5. 检查 STM32 与 MaixCAM2 的串口通信。
  6. 先在低速、限幅条件下调试 PID 参数。
  7. 完成静态平衡后，再启用小车循迹功能。

  ## 调试建议

  - 先单独验证钢球视觉识别。
  - 再验证 STM32 是否正确接收坐标数据。
  - 单独测试每个电机的方向和零点。
  - PID 调试时从较小输出限幅开始。
  - 先调内环，再调外环。
  - 机械结构或摄像头位置变化后应重新标定。
  - 首次运行时应保留急停或断电措施。

  ## 注意事项

  - 烧录前确认 STM32 型号及下载接口配置。
  - 确保主控、视觉模块和电机驱动器共地。
  - 串口两端的波特率、数据位和校验方式必须一致。
  - 电机方向与控制坐标方向不一致时，可能导致正反馈失控。
  - 请勿在未限制速度和行程的情况下直接使用较大的 PID 参数。
  - 实际比赛参数应根据机械结构、负载和场地重新整定。
